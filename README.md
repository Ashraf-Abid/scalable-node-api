# Scalable Node API

A production-grade CRUD REST API built with modern Node.js, developed incrementally as a learning project.

## Tech Stack

- Node.js (v20+) & TypeScript
- Express 5
- PostgreSQL & Prisma ORM
- Zod (validation)
- JWT authentication & bcrypt
- Pino (structured logging)
- Swagger / OpenAPI
- Vitest/Jest & Supertest
- ESLint & Prettier
- Docker & Docker Compose
- GitHub Actions (CI/CD)

## Project Status

This project is being built one small, self-contained step at a time, with each step committed to Git independently. See commit history for progress.
